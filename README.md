# 🎮 3D Mobile Game AI Agent

یک نمونه‌ی آماده و قابل اجرا برای ساخت بازی‌های سه‌بعدی موبایل‌محور در قالب وب‌سایت.

## ✅ امکانات

- بازی سه‌بعدی و موبایل‌محور
- سازگاری با مرورگر گوشی
- کنترل لمسی و کیبورد
- نسخه‌پذیری برای ساخت بازی‌های پیچیده‌تر
- استفاده از Three.js بدون نیاز به ابزار ساخت پیچیده

## ▶️ اجرا

فقط کافی است فایل‌های پروژه را باز کنید یا در سرور محلی اجرا کنید:

```bash
python3 -m http.server 8000
```

سپس به آدرس زیر بروید:

```text
http://localhost:8000
```

## 📁 ساختار پروژه

- `index.html` — رابط اصلی بازی
- `style.css` — طراحی و سبک ریسپانسیو
- `game.js` — منطق بازی و گرافیک سه‌بعدی

## 🎯 هدف این پروژه

این پروژه به عنوان پایه‌ای برای ساخت AI Agent و ابزار ساخت بازی‌های وبی استفاده می‌شود. می‌توانید بعداً آن را به:

- تیراندازی سه‌بعدی
- اجرا روی موبایل با کنترل‌ها و UI شبیه بازی‌های حرفه‌ای
- بازی‌های مپ‌محور و سطح‌دار
- RPG و سلاح‌ها، دشمن‌ها، جمع‌آوری آیتم‌ها

تمدید کنید.

## 🚀 توسعه بعدی

- اضافه شدن دشمن‌های هوشمند
- سیستم سطح‌بندی
- صدا و موسیقی
- انیمیشن‌های بهتر
- سیستم ذخیره‌سازی و امتیاز
- ساخت AI Agent برای تولید خودکار بازی

اگر خواستی، در مرحله بعد می‌توانم همین پروژه را به نسخه حرفه‌ای‌تر تبدیل کنم: FPS، endless runner، یا بازی‌سازی کامل سه‌بعدی با منو، سطح و AI دشمن.
