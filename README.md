# 🚀 Sky Runner 3D

یک بازی سه‌بعدی واقع‌گرایانه و جذاب برای موبایل و وب

## 🎮 ویژگی‌ها

✅ گرافیک سه‌بعدی واقع‌گرایانه با Three.js  
✅ سایه‌ها و نورپردازی حرفه‌ای  
✅ بهینه‌شده برای گوشی‌های هوشمند  
✅ کنترل لمسی آسان  
✅ سیستم امتیاز و رکورد  
✅ بازی‌گیری هیجان‌انگیز و سریع  

## 🎯 نحوه بازی

- **هدایت هواپیما**: از دکمه‌های چپ و راست استفاده کن
- **اجتناب**: از موانع قرمز دور بزن
- **جمع کردن**: سکه‌های طلایی را جمع کن برای امتیاز بیشتر
- **رکورد**: بهترین امتیازت ذخیره می‌شود
