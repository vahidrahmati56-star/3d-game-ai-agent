# 🚗 Car Rush 3D

یک بازی سه‌بعدی موبایل‌محور و ساده برای اجرا در مرورگر.

## امکانات

- گرافیک سه‌بعدی و جاده‌ی شبیه‌سازی‌شده
- کنترل لمسی برای گوشی
- سیستم امتیاز و رکورد
- موانع و سکه‌های قابل‌جمع‌آوری
- آماده برای اجرا مستقیم روی موبایل

## اجرا

برای اجرا، فایل `index.html` را در مرورگر باز کنید.

اگر می‌خواهید در سرور محلی اجرا کنید:

```bash
python3 -m http.server 8000
```

سپس به آدرس زیر بروید:

```text
http://localhost:8000
```

## اجرای روی گوشی

- لینک پروژه را در مرورگر گوشی باز کن
- یا باید روی سرور قرار بگیرد و آدرس HTTP آن را در گوشی باز کنی

## هدف بازی

ماشین خود را در مسیر درست نگه دار و از مانع‌ها دوری کن. جمع‌آوری سکه‌ها امتیاز بیشتری می‌دهد و رکوردتان را بالا می‌برد.
